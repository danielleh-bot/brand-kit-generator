How to read this kit

Each property shows (1) where it appears on the publisher site, (2) how it should apply on today’s Taboola feed surface (TRC card anatomy), and (3) whether it ships via loader CSS / __style__ (Standard), loses fidelity (Partial), needs platform/card markup (Unique), or needs Gen AI / editorial rewrite (Soft). Source visuals are high-fidelity mocks from the brand kit and ideal prototype — tagged prototype provenance when live capture is unavailable.

Standard / MVP Ship today via loader CSS + __style__ on existing TRC selectors.Partial A knob exists but value space is too narrow — A/B possible with fidelity loss.Unique / needs platform Ideal prototype shows it; current feed markup/config has no hook.Soft / Gen AI Not CSS — content/experience translation (tone, headline rewrite, naming).

A/B variant framing

Variant A — MVP (loader paint)

  • Primary brand color — MVP paint — measurable CTR/brand-fit lift with zero platform work.
  • Headline font family — MVP — largest native-feel lever after colour.
  • Card / thumbnail border radius — MVP — sharp vs rounded reads immediately as brand.
  • CTA / See more button — MVP — loader can restyle .tbl-feed-more-btn.
  • Section accent orange dot — Partial — can fake with ::before on header text in loader; not a first-class Transformer prop.

Variant B — Ideal subset (platform / Gen AI)

  • BREAKING / LIVE / OPINION kickers — Unique inventory — one pre-label colour exists; multi-label system needs platform.
  • Editorial voice / sentence-case news — Soft — Gen AI or editorial rewrite of feed headlines.
